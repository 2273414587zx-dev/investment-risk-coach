# Investment Risk Coach

Rule-based AI Agent for a college economics class demo (BSU, Oct 13).

- Input: portfolio total + allocations (Stocks / Bonds / Cash / Real Estate / Crypto) + risk tolerance
- Computes a risk score (1–10) from asset-class risk weights
- Flags over-concentration, crypto and cash-drag positions
- Checks the portfolio against the tolerance's healthy score band
- Gives dollar rebalancing moves toward a target mix

Open **index.html** in any browser to use the agent.
